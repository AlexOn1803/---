# Перекладач екрана (Android)

Затисніть **обидві кнопки гучності одночасно** — і весь англійський текст на екрані
з'явиться **українською прямо поверх оригіналу**. Працює в будь-якому застосунку:
браузер, ігри, меню, картинки з текстом.

- розпізнавання тексту і переклад — **на телефоні** (Google ML Kit), без інтернету
  та без надсилання знімків кудись;
- інтернет потрібен лише один раз — завантажити модель перекладу (~30 МБ);
- плашка з перекладом підбирає колір під фон і розмір шрифту під місце;
- торкніться екрана (або знову натисніть обидві кнопки) — переклад зникне;
- утримуйте палець на перекладі — весь текст копіюється в буфер обміну;
- працює, поки застосунок відкритий (можна вийти на робочий стіл — у шторці буде
  сповіщення «Перекладач активний»); змахнули зі списку недавніх або натиснули
  «Вимкнути» — перекладач вимикається, кнопки гучності знову звичайні;
- окремі натискання гучності, як і раніше, змінюють гучність; під час дзвінка
  і з вимкненим екраном кнопки взагалі не перехоплюються.

**Вимоги:** Android 11 або новіший.

## Як встановити

1. Завантажте APK: вкладка **Actions** у цьому репозиторії → останній успішний запуск
   «Screen Translator APK» → унизу **Artifacts → ScreenTranslator-apk** (zip, усередині
   `ScreenTranslator.apk`).
2. Відкрийте APK на телефоні й дозвольте встановлення з цього джерела.
3. Відкрийте «Перекладач екрана» і натисніть **«Завантажити модель»**.
4. Натисніть **«Відкрити спеціальні можливості»** → «Встановлені застосунки» /
   «Завантажені служби» → **Перекладач екрана** → увімкнути.

### Перемикач сірий або пише «Обмежене налаштування»

Android 13+ так захищає спеціальні можливості для застосунків не з Google Play.
У застосунку натисніть **«Відкрити інформацію про застосунок»** → **⋮** (вгорі праворуч)
→ **«Дозволити обмежені налаштування»** → знову увімкніть службу.

## Обмеження

- Застосунки із захистом від знімків екрана (банки, деякі відеосервіси, приватні
  вкладки) не дадуть зробити знімок — з'явиться повідомлення про помилку.
- Якщо ви призначили на «утримання обох кнопок гучності» системний ярлик спеціальних
  можливостей, система може реагувати на довге утримання — просто натискайте коротко.
- На деяких телефонах (Xiaomi, Huawei тощо) систему потрібно попросити не «вбивати»
  службу у фоні: Налаштування → Батарея → «Без обмежень» для цього застосунку.

## Як це працює

| Файл | Що робить |
|---|---|
| `ScreenTranslatorService.kt` | Служба спеціальних можливостей: ловить комбінацію кнопок, робить знімок (`takeScreenshot`), розпізнає текст (ML Kit Text Recognition), перекладає (ML Kit Translate) |
| `TranslationOverlayView.kt` | Малює плашки з перекладом на місці оригінальних блоків тексту |
| `MainActivity.kt` | Екран налаштування: модель, увімкнення служби, тест перекладу |

## Збирання вручну

Потрібні JDK 17 і Android SDK (або просто відкрийте теку в Android Studio):

```bash
cd screen-translator
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
